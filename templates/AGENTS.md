本文件是本项目的 AI 协作者通用约定。

## 动手前
- 先读项目 `README.md` 和已有配置，从现有脚本确认安装、测试与构建命令，不瞎猜。
- 先看 `git status` 和现有代码，不覆盖或撤销他人的未提交改动。
- 需求或修改范围不清楚时先问，不自行脑补大改动。

## 写代码与改范围
- 一次只聚焦当前任务，不顺手重构、格式化或升级无关代码。
- 保持模块边界，优先复用已有方案；不擅自新增第三方依赖，确需新增时说明原因。
- 不为了跑通测试而删减有效测试或弱化断言。

## 验证与交付
- 改动代码后运行项目相关的测试或检查，如实汇报跑了什么、哪些没跑，不虚报通过。
- 修 Bug 尽量补复现验证；改动对外行为时顺手更新相关文档。

## Git 与安全红线
- 在独立分支干活，通过 PR 提交；**禁止直推 `main`，禁止 `push --force` 或 `reset --hard` 覆盖他人代码**。
- 涉及功能/逻辑/依赖/配置的 PR 不得自行合并，须等团队成员人工 Approve。
- 严禁将密钥、Token、密码、隐私数据写入代码、日志或 PR；不提交 >1MB 大文件和构建产物。
